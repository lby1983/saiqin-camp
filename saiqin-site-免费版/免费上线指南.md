## 二、免费上线步骤（GitHub Pages，约 20 分钟）

GitHub Pages 是 GitHub 提供的免费网站托管，服务器在境外，**不需要备案**，注册完即用。

### 第 1 步：注册 GitHub 账号（10 分钟）
1. 打开 github.com，点 Sign up 注册（用邮箱即可，免费）
2. 按提示完成邮箱验证

### 第 2 步：新建仓库
1. 登录后，点右上角「+」→ New repository
2. Repository name 填：`saiqin-camp`（或任意英文名，会出现在网址里）
3. 选 **Public**（公开）
4. 点 Create repository 创建

### 第 3 步：上传网站文件
方式 A（网页直接传，推荐）：
1. 在仓库页面点 Add file → Upload files
2. 把 `index.html` 和 `images` 文件夹整个拖进去
3. 点 Commit changes

> 注意：必须让 `index.html` 在仓库**最外层**（不要放进子文件夹），图片文件夹名必须是 `images`。

方式 B（GitHub Desktop 客户端，适合以后经常改）：
1. 下载并安装 GitHub Desktop，登录账号
2. File → Clone repository，选中刚才的仓库
3. 把网站文件复制进仓库文件夹，Commit → Push

### 第 4 步：开启 Pages 服务
1. 进入仓库 → Settings（设置）
2. 左侧菜单找到 **Pages**
3. Build and deployment 的 Source 选 **Deploy from a branch**
4. Branch 选 **main**，目录选 **/ (root)**，点 Save
5. 等 1–2 分钟，页面顶部会出现网址：`https://你的用户名.github.io/saiqin-camp/`

这就是你的免费官网，任何人可访问。

## 三、以后怎么改

| 想改什么 | 怎么做 |
|---|---|
| 电话 / 地址 / 文字 | 用记事本打开 index.html，找到对应文字直接改，重新上传覆盖即可 |
| 换照片 | 把新照片压缩后（建议宽度 ≤1600px）命名覆盖 images 里的同名文件 |
| 想用自己的域名 | 后期买域名（约几十元/年），在 Pages 设置里绑定即可，与网站内容无关 |

## 四、重要提醒

- **备案**：GitHub Pages 在境外，**无需 ICP 备案**，别去办。只有把网站放到国内服务器时才需要备案。
- **免费域名陷阱**：不要用 .tk / .ml 这类免费域名绑正式网站，可能被收回。
- **搜索收录**：上线后可以在「百度搜索资源平台」免费提交网址，让百度收录。
- **原始照片**：images_origin 文件夹里是手册里的全部原图（高清单图），需要换大图时从这里取。

## 五、备选免费方案（不想用 GitHub 时）

- **构站网 goz.cn / 凡科免费版**：注册账号 → 选模板 → 改内容 → 发布，30 分钟上线，自带二级域名，适合应急。
- **Gitee Pages（码云）**：国内访问更快，但需要实名认证，且部分新账号无法开通 Pages，GitHub 更省事。
